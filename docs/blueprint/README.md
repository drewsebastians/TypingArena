# TypingArena blueprint index

The canonical product and execution specifications for the integrated closure are:

- `TypingArena_Integrated_Ultimate_Blueprint_v4.md` — current v4 product north star, information architecture, UX contracts, and definition of done. It supersedes v2 for journey decisions.
- `../journey-v4/` — v4 execution evidence, traceability, and readiness reports.
- `TypingArena_Integrated_Ultimate_Blueprint_v2.md` — strategic north star, product doctrine, architecture, and definition of done.
- `TypingArena_Grand_Batching_Plan_v2.md` — dependency-aware execution roadmap, acceptance gates, and closure conditions.

Use the following source-of-truth order when reconciling decisions:

1. Integrated Ultimate Blueprint v4.
2. v4 journey execution and closure evidence.
3. Security/scoring/privacy ADRs and passing regression tests.
4. Current route registry and repository implementation.
5. Integrated Ultimate Blueprint v2 and Grand Batching Plan v2 for historical provenance.
6. Original strategic research and historical Goal-First documents.

The historical Goal-First source documents remain under `docs/goal-first/source/` for provenance. They are superseded by the v4/v2 documents above and must not be deleted.
