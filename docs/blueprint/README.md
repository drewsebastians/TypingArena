# TypingArena blueprint index

The canonical product and execution specifications for the integrated closure are:

- `TypingArena_Integrated_Ultimate_Blueprint_v2.md` — strategic north star, product doctrine, architecture, and definition of done.
- `TypingArena_Grand_Batching_Plan_v2.md` — dependency-aware execution roadmap, acceptance gates, and closure conditions.

Use the following source-of-truth order when reconciling decisions:

1. Integrated Ultimate Blueprint v2.
2. Grand Batching Plan v2.
3. Security/scoring ADRs and passing regression tests.
4. Approved Goal-First Figma information hierarchy.
5. Current repository and tests as implementation reality.
6. Original strategic research and historical Goal-First documents.

The historical Goal-First source documents remain under `docs/goal-first/source/` for provenance. They are superseded by the v2 documents above and must not be deleted.
